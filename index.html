01
Keys · health · config

Settings & Status

Keys, source health, baked data freshness and every subsystem in one place.

Riftbound’s Scrydex lookups need SCRYDEX_API_KEY and SCRYDEX_TEAM_ID in your .env. SWU needs nothing. LEGO uses REBRICKABLE_API_KEY / BRICKSET_API_KEY / BrickLink keys, and Funko pricing uses EBAY_APP_ID / EBAY_CERT_ID. Every builder still works for manual entry with no setup.

Heads-up: the counter above works from the item price only, so it does not include the postage the buyer pays on top. Every listing now carries banded postage, so read it as a floor rather than the full picture.
