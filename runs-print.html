Runs
The verification code is a bearer secret. Whoever reads one can decrypt that bundle's record and learn its contents before the run closes. It goes inside the parcel on the insert and never on the outside, where every courier and sorting facility would see it. The seal carries the run, the number and the serial — never the code.

No monetary value appears on any printed surface, and the page refuses to render if one gets through. Emphasis on these sheets is border weight rather than filled blocks: a box means “stop and do something”, and a filled block would cost ink on every copy.
