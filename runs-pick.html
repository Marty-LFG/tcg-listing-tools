This check advises. It never decides, and it never edits the manifest. A vision model misreads digits, and a certification number is eight of them — so a machine saying "looks right" is not the check, you are. What it does is read what is in the photograph and hand you anything that disagrees with the manifest.

Do this before the run is locked and before anything is sealed. A wrong card found now is an edit; the same card found after the lock needs an amendment, a new published root and a new anchor.

The photograph

lay the contents out flat, labels readable

Photograph the contents laid out and unsealed, with every slab label facing the camera. The certification number is what earns this check its keep — it is the exact field the buyer will type in later — so make sure the digits are sharp. Packs are counted, not identified: which physical pack is which cannot be read from a picture, and this never pretends otherwise.
